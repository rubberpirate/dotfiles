# Dotfiles

Personal Linux desktop dotfiles for a Hyprland-based setup.

## Included configs

- **Hyprland** (`/hypr`)
- **Kitty** (`/kitty`)
- **Fish shell** (`/fish`)
- **Starship prompt** (`/starship.toml`)
- **Fastfetch** (`/fastfetch/config.jsonc`)
- **illogical-impulse** app config (`/illogical-impulse`)

## Repository layout

- `/hypr` – Hyprland, Hyprlock, Hypridle, monitors, and workspace configs
- `/fish` – Fish shell config, aliases, and startup behavior
- `/kitty` – Kitty terminal config and helper scripts
- `/fastfetch` – Fastfetch config plus local media assets
- `/illogical-impulse` – App-specific config and package state files
- `/starship.toml` – Starship prompt theme

## Notes

- This repo is a personal backup and may include machine-specific values.
- Review configs before applying them on another system.
